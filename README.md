## Description
**Pride** _(or Warrior's Pride)_ is a mod that aim to revert Minecraft PvP physics to pre 1.9, while still keeping the content of the Combat Update.

As a long-time PvP player, i've felt disappointed with the "Combat Update" that made Minecraft PvP and PvE feel **slow** and **boring**, by adding the attack cooldown on every weapon, and introducing a way to negate all incoming damage.

**Pride** reworks the **knockback functions**, and **attack cooldowns** to make swords and **fishing rods** from 1.8.9 / 1.7.10 integrate with the new axes and shields. It also tries to replicate the feel of old school PvP by changing the **player's body rotation speed**, and the buckets / sword animation.
